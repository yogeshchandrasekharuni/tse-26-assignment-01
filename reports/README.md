# Report sources and evidence

The editable report is generated by `scripts/build_report.py` from the prose in `reports/content.json`, the frozen contracts, and measured campaign artifacts. Figures are authored vector geometry. Canonical statistics and Wilson intervals come from the evaluated evidence; drawing coordinates may use floating point.

`make report-draft` produces a visibly marked working PDF while the live campaign is incomplete. `make report` must reject incomplete headline evidence or missing full offline reproduction. The final document must contain 10-12 pages and every rendered page must be inspected. No author names have been supplied; none are inferred.

Provider usage is a separate report-side audit of the immutable raw response channels. It does not change the frozen evaluation implementation or its outcomes. Run `scripts/audit_provider_usage.py` on a completed live campaign. The audit includes physical failed attempts, deduplicates reused source executions by scanning physical directories once, preserves unavailable fields as null, and distinguishes recorded responses from provider-attempt telemetry. Cached prompt tokens are a subset of prompt tokens.

Primary references and the limited claims they support are recorded in `sources.json`. These references explain methods and framework behavior; they are not evidence that this application or any experiment ran. Empirical claims must link to repository artifacts.
