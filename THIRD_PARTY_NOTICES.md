# Third-party material

The generated synthetic observations are labeled CC0-1.0 in their data manifest. No ownership or license for the coursework assignment is inferred; its supplied original is retained as source material.

The browser uses unmodified self-hosted Public Sans from `@fontsource-variable/public-sans`, Lucide React icons, React and React DOM. Their supplied license notices are copied into `frontend/public/licenses/` and travel with frontend builds. Lucide's notice includes its Feather-derived icons. Exact installed versions are in `frontend/package-lock.json`.

Python/framework dependencies are resolved in `uv.lock`; their installed distributions retain their own notices. Model weights are not bundled. The local model manifest preserves its supplied Apache license text. Development calibration boards retain their origin register under `.impeccable/references/origins.json`; they are not application assets. UI screenshots document this application's actual rendering.

Report diagrams and prose are editable project sources. The report's research references are citations, not copied full papers or evidence of application execution.
