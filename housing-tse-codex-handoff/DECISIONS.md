## Implementation-time choices that are not blockers now

Select exact available Fast Agent release after probe (inspected main0.10.42is not proof of publication), actual local model digest/hardware fit, charting library, packaging/report renderer and repository name. Lock and record choices. If the suggested7Bmodel cannot run, use a smaller local instruct model only after schema/decision/seed/playback probes; document the substitution and retain the same frozen experiment semantics. Do not silently use a cloud model that cannot honor seeds.

Author names, git remote and instructor submission portal are intentionally unspecified. They do not block building the project. Do not fabricate them. If no model can execute, the deterministic portions remain useful but live evidence, captured corpus and complete empirical report remain outstanding.

## Change control

When discovering a flawed MR or ambiguous contract: record the concrete counterexample/requirement, decide a coherent revision, bump affected schema/catalog/data/prompt/campaign versions, update all dependent docs/tests/templates, preserve previous evidence, then rerun affected headline cases. Do not keep results from incompatible versions in one table. Deadline pressure is not a reason to fabricate execution or quietly reduce30 distinct bases/3 seeds.
