# Execution notebook

Status: implementation template; no application run is documented by this template.

## Environment and frozen versions

Record actual OS/CPU/GPU, Python/Fast Agent/Ollama versions, base/derived model digests, dependency locks, git revision/dirty state, prompt/schema/MR versions and UTC timestamps.

## Chronological record

For each meaningful step: actual command, purpose, inputs/seeds, output paths/hashes, observed result, interpretation, limitations and next action. Include unsuccessful commands and AI-suggested errors that mattered. Never fill this with commands that were only planned.

## Data freeze

Record generated bytes/rows/month coverage, quarantine report, SHA checks, recipe/runtime, regeneration check, synthetic limitations.

## Framework and loop proof

Link actual probe and live feedback trace. Identify Reviewer decision, changed strategy/specialist set, unchanged criteria and stop condition.

## Pilot and frozen campaign

Record pilot throughput and any changes before freeze. Link final cohort/seed/experiment manifests. Record900 expected pairs and actual statuses, source reuse, model call totals and observed cost/runtime.

## Results and diagnosis

Link actual table/CIs, actual top 3RCA or fewer-failures explanation, pre/post-fix campaigns and regression evidence. Keep controls separate.

## Reproduction and submission

Record actual clean-checkout setup, disconnected reproduce output, table comparison/hash, UI screenshots, report render/page count and submission-check. List any missing evidence plainly.
