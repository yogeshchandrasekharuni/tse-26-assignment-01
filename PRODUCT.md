## Platform

web

## Stack

React and TypeScript frontend, FastAPI backend, one shared Python analysis service, and Fast Agent agents as tools. These are specified by the user's accepted implementation goal. Local development and reproducible offline evidence are required; no public deployment is requested.

## Users

Confirmed setting: an IIIT Hyderabad TSE coursework submission, teams of two. Working audience assumption delegated to implementation: student developers exploring housing slices and a course reviewer inspecting agents, metamorphic evidence and reproduction. No consumer real-estate advice is implied.

## Product Purpose

Let a user select a residential listing slice, inspect its twelve-month trend, understand how agents reached the result, and investigate whether ten input transformations preserve their declared statistical relations.

## Positioning

Real model decisions coordinate specialists, while exact Python tools establish statistical truth. The same production service drives application analysis and paired metamorphic experiments. Strict offline playback reruns tools and control flow from captured model responses.

## Operating Context

The frozen local synthetic Dallas-themed feed contains34,560 observations over October2024–September2026 and twelve allowed ZIP codes. No addresses, private listing data, paid credentials or live-market claims. Users work with month labels, observation counts, exact price/ppsf strings, regional ranks, model decisions, receipts and source/follow-up comparisons.

- Explore, Workflow, Experiments and Provenance are required application areas. Desktop and390px mobile must work.
- The Orchestrator is the only public agentic entry/exit. Price, Supply, conditional Region, Reviewer and Composer remain internal.
- Criteria remain immutable during feedback; strategy and active specialists can change. Distinguish complete, limited, empty, loading and failed runs.
- Display values and canonical statistics come from the backend. Expose units, data/model/seed provenance, exports and trace detail.
- Real live and replay evidence have distinct labels. Pilot, injected controls and headline results remain separate. Do not fill missing experiments with invented values.
- The assignment deadline is16 October2026; no submission hour or author names are inferred.
